# Backlog

## 1. Purpose and rules

Deferred opportunities, needs, and ideas for [project]. This optional side channel requires no approved strategy or release. An entry is an option, not release selection, scope approval, execution authorization, or delivery evidence. Roadmap/spec/plan/tasks retain their canonical decisions and controls.

Keep one current row per stable BNNN ID. Never reuse IDs or delete an item to record its disposition. Notes and history refer to the same ID. Preserve original dates/sources and existing priority order; only explicit reprioritization moves an existing item. Adapt older layouts only within authorized maintenance, retaining their content and references.

Priorities: **P0 Critical → P1 High → P2 Medium → P3 Low**. Default to **P2 provisional** only when priority is unspecified. Record the basis of evaluated/changed priorities in the notes or history. Priority here does not select or reprioritize a release.

Dispositions: **Pending** (being considered), **Deferred** (postponed with a reason), **Incorporated** (wholly represented in a valid spec draft), **Discarded** (no longer considered, with a reason), **Merged** (consolidated into an identified item). These are documentary labels, not controller states. Incorporated does not mean approved, implemented, accepted, or delivered.
