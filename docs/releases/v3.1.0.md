# Spec-Flow v3.1.0

Release date: 2026-10-16.

## Added

Choose model and effort for the orchestrator, implementer and independent reviewer through validated, atomic `configure-profiles`. New projects default to `gpt-6.1-sol/low`, `gpt-6-luna/high` and `gpt-6.1-sol/medium`. Existing configs remain intact. Runs and hashed packets pin their profiles; later config edits affect only new runs. Actual native identity and host availability checks remain mandatory, without silent fallback.

## Changed

Eight canonical document templates now start with YAML frontmatter before the title. Existing fenced JSON documents remain readable with their historical digests; generated status updates preserve source encoding. Internal config, events and registries remain JSON. The strict bounded YAML loader bundles licensed pure-Python PyYAML.

## Compatibility and controls

No automatic conversion or project migration. Converting an approved source remains an explicit revision requiring existing approval and downstream adoption controls. Old runs retain their historical profiles and packet hashes. Exact dependency digests, explicit execution authorization, isolated linked worktrees, one active implementer, three-attempt limits, independent phase review and evidence-based closure remain enforced.
