# Spec-Flow v3.0.1

Release date: 2026-10-16.

## Fixed

The primary listing icon was not declared in v3.0.0, so the catalog could show a generic document icon even though the designed PNG was packaged. Both manifests now declare `logo` and `composerIcon` as `./assets/spec-flow-icon.png`. The existing image is unchanged. A packaging regression check verifies both declarations, mirrored manifests and contained packaged assets.

## Verification and traceability

The functional workflow, controller, hook, skills and templates are unchanged from v3.0.0. Original [E7](../implementation/e7-ef7897d.md), [candidate E8](../implementation/e8-ef7897d.md), [final 3.0.0 installation](../implementation/e8-d19d6e0.md) and [3.0.0 publication](../implementation/publication-v3.0.0.md) retain their original commits and scopes; this patch does not reinterpret them as new executions.

Fresh v3.0.1 package and isolated installation checks are recorded in [patch verification](../implementation/release-v3.0.1.md). Manifest/asset validation proves the declaration and file are available; it does not by itself prove the visible catalog refreshed in an existing app session. No user installation/update or project migration is performed by publication.
